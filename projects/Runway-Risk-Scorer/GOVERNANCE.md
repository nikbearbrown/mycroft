project (principles P1–P8: labor separation, verified data layer, provenance,
human gates, two-customer logging, lifecycle status, etc.). The constitution
text is **not reproduced here** — the upstream repo is all-rights-reserved.
This repo references and complies with it.

## Solo-development honesty note
While developed by one person, the P4 human gate has no independent reviewer.
Gate decisions in `logs/RUN_LOG.md` are therefore recorded as **acting-reviewer,
SOLO**, and each records what could **not** be independently verified. Status
in the recipe frontmatter is only advanced when matching evidence exists in the
run log — never on feeling.
