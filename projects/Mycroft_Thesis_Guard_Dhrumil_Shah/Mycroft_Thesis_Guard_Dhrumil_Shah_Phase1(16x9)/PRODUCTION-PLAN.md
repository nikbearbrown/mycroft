# 10-scene production plan

All timing is frame-locked at 24 fps. The visual rule is: **one idea → one
visual → progressive reveal → visible evidence → clear transition**.

## Transition logic

The film uses gentle fade/translation through a continuous cream background;
there are no abrupt “slide” cuts. Each scene’s opening headline appears first,
then the claim’s supporting artifact and the accompanying values. The title
hold is intentionally silent so the final takeaway can be read at 4K.
