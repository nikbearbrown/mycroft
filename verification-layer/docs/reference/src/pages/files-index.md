the Files pages. [[tests/test_docs_coverage.py]] fails if a file has no entry. Generated files
(`web/frontend/dist/`, `node_modules/`, `__pycache__/`), local data (`web/data/`), `env/`, `.env`
and the author's working folder `divij/` are gitignored and not part of the project listed here.
