# Synthetic Finance History

These January and March packs extend the existing February sample into a
three-period history for deterministic comparison tests. All entities, amounts,
customers, transactions, and operating records are synthetic.

The packs may be used only for validation, calculation, orchestration, testing,
and demonstration. They are not forecasts, approved accounting records, or
evidence about a real company. Each period must pass the same raw-to-verified
controls as the original sample before the trend tool can read it.
